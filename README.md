# Wuu Music

一个基于 Electron 构建的简洁现代化本地音乐播放器，集成多平台歌单导入、在线解析、损坏歌曲修复、桌面歌词与歌单分享等能力。

## 项目概述

Wuu Music 以"本地音乐管理 + 多源扩展"为核心设计目标。主进程负责协议注册、模块装配、生命周期管理与 `music://` 自定义协议处理；渲染层通过 `contextBridge` 暴露的多组 API 与主进程交互，所有功能模块均采用 `require 即自动注册 IPC handlers` 的装配方式，便于扩展与维护。

### 核心特性

- 本地音乐库扫描与播放，支持 AAC/MP3/WAV/FLAC/M4A 等多种格式
- 多平台歌单导入：网易云音乐、酷狗音乐、汽水音乐
- 多平台分享链接解析下载：汽水、网易云、QQ、酷我、咪咕、Bilibili、5sing、千千、Jamendo、JOOX、Apple Music
- Soda 音频解密（AES-CTR + MP4 box 原语）
- 封面主色调提取，自适应配色
- 桌面歌词窗口（支持锁定穿透、拖拽、位置持久化）
- 损坏歌曲扫描与修复（重新拉取、歌词重建、名称修正）
- 免费听音乐专区（基于 `music-dl.exe` 本地 Web 服务）
- 歌单分享（`wuu://` 协议 + 本地 HTTP 服务器 + 加密地址）
- 多账号管理与切换

## 技术架构

### 主进程模块装配

入口 `main.js` 仅负责协议注册、菜单移除、模块装配与应用生命周期，所有业务逻辑拆分至各功能目录。

```
main.js
  ├── core/         基础层：日志 / 共享状态 / 配置存储 / 网络工具
  ├── audio/        音频层：扫描 / 时长解析 / 文件校验
  ├── soda/         音频解密：AES-CTR + MP4 box 原语
  ├── cover/        封面色彩提取
  ├── window/       窗口管理：主窗口 + 桌面歌词窗口
  ├── download/     在线解析下载
  ├── repair/       损坏歌曲扫描与修复
  ├── free-music/   免费听音乐专区（music-dl.exe 服务管理）
  ├── kugou/        酷狗音乐歌单导入
  ├── qishui/       汽水音乐服务
  ├── netease/      网易云音乐歌单导入（内嵌 NeteaseCloudMusicApi）

  ├── playlist/     歌单导出导入（wuu:// 协议）
  └── parsers/      多平台解析器注册中心
```

### 自定义协议

#### music:// 协议

通过 Node.js `fs` 读取文件流，绕过 Chromium `file:///` 的 MAX_PATH 260 限制，支持 Range 请求以实现音频缓冲与跳转。MIME 类型根据扩展名自动映射。

#### wuu:// 协议

歌单分享专用的自定义协议，v1 版本格式：

```
wuu://<base64url(JSON{v, f, b, j, jc, r, dt, d, p})>
```

字段说明：

| 字段 | 含义 |
| --- | --- |
| v | 协议版本 |
| f | 分支型号（produce/exploitation/test） |
| b | 版本数据 |
| j | 兼容性类型 |
| jc | 兼容版本列表 |
| r | 保留数据 |
| dt | 地址类型（dIP / ddomain） |
| d | 加密地址数据（AES-256-GCM + XOR 偏移） |
| p | 加密端口（格式头 + 字母混淆，无数字） |

密钥与链接分开发送，远程拉取时通过 `http://<host>:<port>/playlist/<id>?k=<accessKey>` 获取歌单数据。

### IPC 通信

渲染层通过 `preload.js` 暴露以下 API 命名空间：

| 命名空间 | 职责 |
| --- | --- |
| `musicAPI` | 本地歌曲、歌词、用户数据、封面色彩 |
| `windowAPI` | 窗口最小化、最大化、关闭、退出 |
| `desktopLyric` | 桌面歌词显示、锁定、位置 |
| `parseAPI` | 分享链接解析与下载 |
| `repairAPI` | 损坏歌曲扫描与修复 |
| `freeMusicAPI` | 免费听音乐专区（搜索、试听、下载） |
| `kugouAPI` | 酷狗音乐登录与歌单导入 |
| `qishuiAPI` | 汽水音乐登录与歌单导入 |
| `neteaseAPI` | 网易云音乐登录与歌单导入 |
| `playlistAPI` | 歌单分享、服务器管理、密钥导出导入 |

## 安装与使用

### 环境要求

- Node.js（建议 18 及以上）
- Windows 操作系统（当前版本主要面向 Windows）

### 安装依赖

```bash
npm install
```

安装完成后会自动执行 `scripts/patch-kugoumusicapi.js` 对酷狗音乐 API 依赖进行补丁处理。

### 开发运行

```bash
npm start
```

### 构建打包

```bash
npm run build
```

构建配置使用 `electron-builder`，目标为 Windows NSIS 安装包，输出目录为 `dist/`。

## 核心功能说明

### 多平台歌单导入

支持三个平台的官方账号登录与歌单导入，均支持多账号管理与切换：

- **网易云音乐**：二维码扫码 / Cookie 导入登录，内嵌 `NeteaseCloudMusicApi`
- **酷狗音乐**：二维码 / 手机号验证码登录，内置 `kugoumusicapi`
- **汽水音乐**：二维码 / 一键登录 / 凭证文件登录，本地解密音频

### 在线解析下载

通过 `parsers/` 注册中心统一管理多平台分享链接解析。当前支持的平台包括：汽水音乐、网易云、QQ、酷我、咪咕、Bilibili、5sing、千千、Jamendo、JOOX、Apple Music。

解析流程：分享链接 → 识别来源 → 解析歌曲信息 → 下载音频（可选 Soda 解密）+ 封面 + 歌词 → 写入 `output/歌曲名 - 艺人/` 目录。

### 损坏歌曲修复

扫描 `output/` 目录下的歌曲，检测以下问题并提供修复：

- 解密失败（仅有 `.enc.m4a`，无可用音频）
- 音频缺失
- 文件过小
- 歌词精度不足
- 名称异常（从 FLAC VORBIS_COMMENT 读取真实标题重命名）

修复方式：音频问题用 `trackId` 重新下载；歌词问题从 `lyrics_krc.json` 重新生成。

### 歌单分享

通过本地 HTTP 服务器（默认端口 30967）提供歌单分享能力：

- 支持 IP 绑定（`0.0.0.0` 监听所有网卡 / 特定 IP）
- 客户端白名单（支持通配符，如 `192.168.*.*`）
- 频率限制（每 IP 每分钟最大请求数）
- 访问日志记录（最多保留 500 条）
- 歌单支持过期时间与次数限制
- 密钥可导出为本地 `.crt` 文件，与链接分开发送

### 桌面歌词

独立的桌面歌词窗口，支持：

- 显示 / 隐藏切换
- 锁定 / 解锁（锁定后鼠标穿透）
- 拖拽改变位置并持久化
- 颜色自适应（基于封面主色调）

### 免费听音乐专区

后台启动 `music-dl.exe` Web 服务（固定端口 17324），通过 HTTP API 提供搜索、试听、下载、歌词、换源等能力。该模块设有免责声明，用户需明确接受后方可使用。

服务管理特性：

- `windowsHide: true` 隐藏子进程窗口
- 过滤 GIN 请求日志，仅保留关键事件与严重错误
- 应用退出时自动终止子进程

## 安全说明

- 所有 IPC 通信通过 `contextBridge` 隔离，渲染层无法直接访问 Node.js API
- 歌单分享服务器支持白名单、频率限制与访问日志，可控制访问范围
- 分享链接使用 AES-256-GCM 加密地址与端口，密钥与链接分离传输
- 免费听音乐专区的 `music-dl.exe` 仅监听本地 `127.0.0.1`，不对外暴露
