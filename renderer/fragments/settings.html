其他页面跟随封面配色
开启后列表/统计/设置/解析等页面也会应用当前歌曲封面的渐变背景
封面统一性
开启后试听模式下换源时保持原封面不变 (与列表显示一致), 切歌时正常更新为新封面; 关闭后换源时封面跟随新源变化
桌面歌词持久化
开启后每次启动软件自动打开桌面歌词, 无需手动开启
桌面歌词位置
拖动桌面歌词窗口后位置自动保存; 点击重置恢复默认居中位置
低精度歌词模拟走字
对无逐字精度的歌词(行级LRC),在两行时间戳间均匀模拟逐字填充进度,获得近似走字效果(默认关闭)
歌手分组模式
桶包含: "洛天依/言和"共创歌曲归入"洛天依/言和"一个分组; 拆分: 拆成"洛天依"和"言和"两个分组, 歌曲同时出现在各自分组下 (支持 / ／ & ＆ 、 , ， ; ； | feat./ft./with/x 分隔符)
进度条颜色
启用后使用自定义颜色(支持两色渐变过渡), 关闭则跟随当前歌曲封面色

点击暂停时音量在 0.5 秒内平滑淡出（类似网易云音乐），关闭后立即暂停
网络服务
开启歌单分享服务
开启后本地启动 HTTP 服务器, 允许其他设备通过 wuu:// 链接拉取你的歌单。默认关闭, 仅在需要分享时开启
开启手机版访问
开启后可通过手机浏览器访问移动端 UI, 播放本机歌库音乐。与歌单分享共用同一端口和 IP 绑定设置。访问地址: 本机IP:端口
服务端口
HTTP 服务器监听端口 (1-65535), 默认 30967
对外地址
生成分享链接时使用的地址。软件部署在公网服务器或使用内网穿透时, 自动获取的本机 IP 可能是内网地址 (如 192.168.1.4), 此处可固定为公网 IP 或域名, 不含端口号 (端口由"远程端口"控制)。例: 8.153.37.78 或 example.com
远程端口
生成分享链接时使用的端口。frp 等内网穿透转发时, 远程端口可能与本地服务端口不同 (如本地 30967 → 公网 18967), 此处填入公网侧端口。留空则使用"服务端口"。
高级网络设置 (IP 绑定 + 白名单 + 频率限制 + 日志) ▼
IP 源绑定
0.0.0.0 = 监听所有网卡 (允许局域网访问); 127.0.0.1 = 仅本机访问; 或填入特定网卡 IP
客户端 IP 白名单
每行一个 IP, 支持通配符 (如 192.168.*.*)。留空 = 允许所有 IP 访问; 本机始终放行
频率限制 (每 IP / 分钟)
限制每个客户端 IP 每分钟最大请求数, 防止恶意刷接口。0 = 不限制; 推荐 30~120。本机访问不受限制
次/分钟
访问日志记录
开启后记录每个客户端的访问行为 (哪个 IP 下载了哪首歌/访问了哪个歌单), 最多保留 500 条
