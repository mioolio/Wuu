# 正在播放：布局、颜色与交互约定

全部特性见 [README](../README.md)，模块算法与协议见 [技术实现说明](TECHNICAL_ARCHITECTURE.md)。本文说明当前源码中的播放器行为与验证入口。

原界面设计参考本地安装的 UI/UX Pro Max 技能。历史设计来源：
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
版本：`09170eec67eefd46a7ae85de61b40c194020f997`。

已验证的技能检索：`music streaming --domain product`、
`animation reduced motion --domain ux`、`interrupt --domain ux`、
`animation effect cleanup --stack react`、`rapid text transition interrupted --domain ux`。采用音乐产品的暗色背景、封面配色与明确的内容层级；不套用检索输出中面向营销网站的页面结构。

## 布局

- 封面、歌名、歌手、专辑、收藏操作采用同一条中心轴；歌名位于封面正下方。
- 唱片区域向内容中心收拢，宽屏不无限拉开封面与歌词的距离。
- 歌词栏整体向左收拢 16–28px，行内仍居中；不单独偏移某一行歌词。
- 原封面中央不叠加穿孔、轴心或遮挡；唱片模式仅保留外缘与旋转效果。
- 歌名允许两行；专辑等次要信息截断时保留完整标题提示。
- 封面尺寸同时受实际舞台剩余高度约束；标题和操作优先保留，封面等比缩小，避免长歌名时操作区被底栏遮住。作词、作曲紧接歌名下方显示，仅使用真实署名；没有署名时隐藏。歌词区域只保留歌词，不在底部放置署名或其他文件信息。
- 音效仅保留底部右侧常驻入口；添加歌单只显示加号，分享、不喜欢和评论同排采用图标。时长与专辑归入次要信息行。
- 长短歌词居中，长句完整换行，原文与译文可以纵向浏览。超过可读区的当前行从开头显示，不使用横向跑马灯裁切正文。
- 在 800×500 的最小桌面窗口中，播放、进度、音效、桌面歌词、音量和队列保持可见。
- 推荐页音乐库摘要在内容宽度不足 740px 时排到列表下方，数字采用两列自适应网格，避免大歌库计数挤出卡片。
- 当前歌词字号仅在设置的歌词分类调整（最高 60px），普通字号收于高级选项，分别即时生效并保存。唱到时使用当前字号，逐字进度跑完或整句声明时长结束后仍保留放大；只有下一组歌词开始显示时，上一组才恢复普通字号。RAW/KRC、增强 LRC 和普通 LRC 使用同一焦点规则；最后一组保持突出直到换歌。未播放的歌词保持白色，已播放的歌词采用歌词主题色；当前行通过独立字号和字重突出，取消选择条，行内已唱部分着色、待唱部分保持白色。同时间戳原文与译文成组判断，后退或跳转时重新计算状态。
- 分享在当前歌曲图标附近打开浮层，生成与复制链接不切换页面；分享有效期和访问次数收于展开选项。评论浮层下的歌曲风格二级菜单支持选择已有风格、新建个人标签、保存与恢复音频标签，供最近聆听风格统计使用。
- 旧版切换直接使用仓库 `renderer/` 中的原界面与桌面歌词，切换时保存并恢复本地歌曲、进度、播放／暂停状态及共用数据，不以 CSS 仿制旧版。
- 普通播放页直接展示封面与歌词，移除「正在聆听」状态头。封面变色与不透明度仅在设置的外观区域调整，拖动仍即时生效。
- 新版顶部品牌区和右侧空白区各自声明原生窗口拖动范围，最小化、最大化和关闭按钮单独排除拖动；窗口边缘保留系统调整大小范围。
- 新版「设置 → 外观 → 实验性外观」提供默认关闭的 Apple 风格：红色关闭、黄色最小化、绿色最大化／还原，配合深色中性分层、圆角侧栏选中项与分组控件。启用后可选择窗口按钮在左侧或右侧；左侧采用关闭／最小化／最大化，右侧采用最小化／最大化／关闭，保留各自的操作习惯。窗口操作继续使用现有行为，关闭仍隐藏到托盘。开关与位置即时生效并保存，关闭恢复原外观，再开启保留上次位置，不重置透明度、封面配色、侧栏或播放偏好；旧版与手机页面不应用此主题。
- 同一区域提供独立、默认关闭的「磨砂玻璃（实验性）」，使用系统原生的窗口后背景模糊：Windows 11 22H2（build 22621）起使用 Desktop Acrylic，macOS 使用 behind-window vibrancy。不支持的系统禁用开关并说明原因，不用 CSS `backdrop-filter` 假冒桌面模糊。开关立即应用并保存，沿用界面不透明度和封面配色，可与 Apple 风格及左右窗口按钮组合。启动时按保存偏好应用；切入旧版撤销原生材质，切回新版恢复偏好，关闭后恢复普通透明背景。系统可能按透明效果、节能或窗口活跃状态使用材质后备色，应用不改变系统设置。依据：[Electron v33 文档](https://github.com/electron/electron/blob/v33.4.11/docs/api/base-window.md#winsetbackgroundmaterialmaterial-windows)、[Microsoft Acrylic](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)。

## 启动与后台整理

- 歌曲列表先返回本地音频路径、已有歌曲信息和缓存标签，不等待全库音频的曲风解析；曲风在后台读取，按路径增量补充，不重开音频或跳转播放进度。
- 页面和播放栏从启动时即可使用，取消覆盖所有页面的「正在整理你的音乐」等待屏。首次读取超过 500ms 才显示轻量状态提示，该时间只控制提示，不延迟页面和播放；后台曲风解析不显示阻塞界面。
- 原用户数据完整加载成功前不写盘。启动期间先听歌、修改设置、收藏或手工曲风的操作，在原数据到达后按顺序合并；迟到的自动恢复不覆盖用户已选歌曲，已删除歌曲不会被迟到的标签重新插入。
- 初始化立即发起读取；已返回的用户偏好和歌曲一次发布，避免先呈现默认外观再替换。用户数据仍在等待时，基础歌曲继续先显示，页面与播放不等待完整整理。
- `node scripts/startup-desktop.cjs` 使用隔离数据、真实生产构建和原生音频，将标签解析与用户数据分别延迟，验证等待期间播放、页面切换及迟到更新不会中断聆听。

## 上一首与播放历史

- 桌面随机播放在当前会话中保留未抽取歌曲，当前播放范围的一轮全部抽取后才重新洗牌；有多首歌曲时避免轮次交界连续重复同一首。播放次数和热度不参与随机权重，零次播放歌曲同样进入队列。
- 重选当前歌曲、在同一播放范围内手动点歌、修改播放模式或刷新歌曲信息，不再重洗整轮；手动点歌仅移出所选项。增删歌曲和标记不喜欢时按音频路径更新未抽取列表，保留其他未播歌曲。明确手动重播和沿历史回退仍可重听，退出客户端后重新建立会话轮次。
- 随机播放按实际成功播放的歌曲保留当前会话历史；跨洗牌轮、手工选歌或修改播放模式不丢掉已听路径。上一首沿历史返回，回退后的下一首先沿原历史前进，再抽取新歌曲。
- 已删除或标为不喜欢的本地歌曲跳过；顺序与歌单播放仍保留队列首尾循环。在线试听保存真实已播放的来源与队列位置，上一首不重新随机抽歌，失败或迟到的解析不写入已听历史。
- 手机端按音频路径重新定位现歌库中的历史歌曲，避免删除后索引改变而返回错歌；历史读取失败保留当前歌曲，不用随机歌曲代替。没有历史时，列表模式仍可顺序返回。
- `npm run test:previous` 使用真实播放按钮、原生音频和三首隔离歌曲，验证反复点当前队列项仍完成三轮覆盖、跨轮连续回退和再前进、暂停与进度保留，以及列表首尾循环。
- 经典桌面界面同样按音频路径保留每个实际播放范围的剩余轮次，不再因手动选歌跳过随机队列前半段。浏览其他歌单只改变显示，下一首仍在开始播放时选择的歌单内；随机队列排除不喜欢歌曲。`node --test renderer/tests/shuffle.cjs` 验证经典生产函数的轮次和范围。

## 新曲发现

- 推荐页从网易云公开歌单随机抽取候选，排除歌库中的平台歌曲 ID，以及规范化后同名、共享歌手的歌曲。公开歌单抽样不等同于全网均匀随机。
- “换一批”优先使用未展示的候选，再轮换公开歌单分类与目录页；当前会话已展示歌曲也会排除，空歌库同样可发现新歌。
- 试听使用现有标准音源能力并尊重曲目可用性，显式保存后才加入歌库。保存后立即从候选中移除。
- 加载和错误有明确反馈，网络失败保留上一批结果，不回填本地歌曲；快速试听只采用最后的播放请求，离开推荐页后不会被迟到结果强制跳回。

## 颜色

- 正在播放的歌词、桌面歌词和播放进度默认采用封面取色。
- `themeFollowCover` 只决定是否扩展到全局主题，不得关闭歌词的封面配色。
- 自定义颜色优先；关闭自定义后立即恢复封面色。
- 取色须兼容真实 IPC 的颜色数组；无封面、加载失败和快速换曲必须有确定的回退颜色。
- 亮度调整只用于提高暗色界面的可读性，不得把有彩封面误判为灰色。
- 桌面歌词窗口订阅完成后主动请求当前状态，确保晚打开、重开仍收到歌词与配色。
- 新版桌面歌词每次打开都在显示前同步歌曲、歌词、时钟、设置和颜色的完整快照，收到本次内容提交的确认后才显示窗口。封面取色尚未完成时，文字等待实际结果；自定义颜色和确定的无封面回退可立即显示。首个可见帧直接采用目标颜色，后续颜色变化才使用过渡，避免默认粉色闪烁和重开时残留上一首颜色。

## 动效与交互

- 新封面实际加载完成后再替换，旧封面短暂保留完成淡出；快速切换隔离旧请求。不得用固定解码期限把后台等待误判为加载失败。
- 主封面与底栏封面主动加载；加载失败后有限重试，窗口回到前台、页面重新可见或网络恢复时可再次加载。长等待保留占位和状态提示。
- 同一图片任一位置恢复成功后，通知仍处于失败状态的可见缩略图重试；只消费本次请求之后的成功记录，避免重试循环。
- 刷新歌库改变当前歌曲封面时，同步歌词配色和系统媒体封面；旧请求的迟到成功或失败均不得覆盖新状态。
- 颜色平滑过渡、当前歌词进入、按钮反馈采用符合各自用途的时长；不使用持续装饰性运动分散听歌注意力。
- 点击歌词定位到所选行；手动浏览暂时停止跟随，计时后恢复，即使音乐暂停也有效。
- 键盘焦点可见且不被自动滚动抢走；所有图标按钮具有可访问名称。
- 系统减少动态时取消旋转、位移和跑马灯，歌词进度及最终状态仍正确。
- 动效结束事件不能承担必要的业务状态更新；清理订阅、计时器与动画帧。
- 新版桌面歌词正常换句时，下一时间戳组的预告文字从下方实际位置上移并放大到当前句位置，旧句同步上移退场，约 280ms 完成；同时间译文跟随当前组，不误当作下一句。逐字填充即时跟随音频时钟。跳转、切歌或再次切句取消上次过渡，最多保留旧、新两层；减少动态时直接显示当前句，不留退场层。
- 悬浮歌词只展示文字，不显示锁定或关闭按钮。软件底栏以及设置的歌词区域控制开关与锁定；锁定后鼠标穿透，解锁后可拖动，位置继续保存。
- 新版「设置 → 播放」提供 0.5×–2× 的播放倍速，步长 0.25×，默认 1×并保持音调；偏好即时保存，切歌、重开及新旧界面切换继续使用。歌词时钟外推乘以实际 playbackRate，暂停、跳转及速度变化立即重新锚定。旧版设置使用相同偏好。
- 推荐页封面按钮在悬停、键盘焦点和按压时保持透明，取消厚重黑色阴影；反馈采用轻微位移、播放按钮和可见焦点。
- 推荐与正在播放使用浏览器原生页面快照过渡：只捕获全尺寸内容宿主，玻璃背景保持实时、固定位置和用户设置的不透明度；页面退场与入场统一 320ms，同封面连续移动 620ms。只有同源且加载完成的矩形封面参与共享；共享封面使用始终完整显示的单一图片层、正常混合与圆角裁切，避免旧、新图层不同淡出时长和阴影留下黑色方块。唱片模式及滚动离开推荐页头部时保留普通页面过渡。
- 页面和音频实例保留，底栏不参与位移。切换目标页面时取消前一次快照；重复点击当前页保留正在进行的入场动画。旧回调不得覆盖最后一次导航。隐藏窗口及减少动态效果直接落实最终页面。
- 首次内容轻微错峰出现，备用动画只移动页面内的内容，不移动滚动视口。按钮按压 160ms，菜单 180ms。键盘焦点享有与悬浮一致的卡片反馈。
- 主内容采用持续存在的右侧滚动条，几何变化 380ms、显隐 180ms。保留真实滚动区域和虚拟列表；拖动、点击轨道和键盘都能操作，手动滚动时滑块即时跟随。
- 导航选中标记沿位置移动 360ms，按钮背景分别过渡；取消根页面快照，固定播放栏、导航和滚动条在页面过渡期间保持实时反馈。
- 音效、歌单弹窗与队列退场 170ms；快速关闭和重开保留表单值并接续当前视觉状态。弹窗挂载于继承主题的应用外框，覆盖完整窗口，不随页面快照移动。关闭立即取消交互，减少动态设置直接关闭。
- 弹窗圈定键盘焦点，关闭返回入口；内层新建歌单提示只处理自身 Escape。静音恢复之前音量，均衡器频段详情随键盘焦点同步。
- 实现参考浏览器官方说明：https://developer.chrome.com/docs/web-platform/view-transitions/same-document

## 验证入口

- `npm run build:desktop`：类型与生产构建。
- `npm run build:mobile`：移动网页生产构建。
- `npm test`：桌面与移动端播放器、歌词、存储与颜色逻辑。
- `npm run test:mobile-ui`：使用生产 Vue 页面、手机尺寸、真实音频和延迟 HTTP 响应，检查首次暂停时歌词定位、点击跳转、重开、播放跨行与快速切歌。
- `npm run test:together`：执行真实服务器房间与移动 welcome 消费逻辑，验证暂停、跳转、任意成员切歌、迟到加入与主持人继任的快照。
- `node scripts/smoke-desktop.cjs`：真实 Electron 播放与基础交互。
- `node scripts/visual-desktop.cjs`：多窗口尺寸与截图检查。
- `node scripts/player-polish.cjs`：真实封面提色、居中、歌词跟随、桌面同步和设置回归，以及隐藏/最小化启动、超过 8 秒的后台换图、失败恢复和封面中央像素检查。
- `npm run test:desktop-lyrics`：真实 Electron 的桌面歌词首个可见帧、延迟封面提色、暂停重开、自定义颜色与无封面回退，真实上移的换句中间帧、快速跳转／切歌清退、倍速同步与设置保存，以及减少动态效果。
- `npm run test:motion`：真实原生过渡 8%/50%/90% 帧的玻璃几何、不透明度及截图边缘像素，宽窄页面和 800×500 窗口、快速打断、备用动画、双向封面过渡、歌词左移、收藏摘要计数、弹层焦点、滚动保留和减少动态回归。
- `node scripts/discovery-desktop.cjs`：真实生产界面与 IPC，验证外部歌曲排重、换批、网络失败保留、并发试听、显式保存与空歌库发现。

- `npm run test:startup`：完整用户数据和曲风延迟时，先播放并保留早期操作，后台更新不重开、暂停或跳转音频。
- `npm run test:previous`：真实随机播放历史、连续返回与前进及顺序播放首尾。
- `npm run test:titlebar`：Windows 真实窗口的原生命中测试，覆盖右侧空白、推荐／设置切页、窗口宽度与缩放、最大化，以及最小化／最大化／还原／关闭按钮的实际 IPC；在独立配置的测试窗口中执行。
- `npm run test:apple`：通过新版外观设置开启 Apple 风格，检查左右位置与按钮顺序、重开保留、关闭恢复、原有外观偏好与新旧版切换，再运行原生拖动区域和窗口按钮回归。
- `npm run test:frosted`：原生材质支持与恢复单元测试，以及隔离 Electron 窗口的磨砂开关、持久化、新旧版切换与 Apple 外观组合回归；Windows 检查实际 DWM 属性，并在自建背景上捕获窗口合成像素验证背景模糊。
- `npm run test:detail`：检查右侧滚动条和导航标记的实际中间帧、拖动与键盘操作、弹窗和队列的可中断退场、焦点返回、均衡器键盘选择及静音音量恢复；生成实际 Electron 交互录屏。

Electron 验证使用 `.test-artifacts` 内的独立数据和窗口，不修改个人歌库。

本轮修正了初始化请求延后发起时触发的立即切页回归：恢复立即发起读取并保留失败重试保护。在本机 Electron 33 的最终生产构建中，默认立即暂停切页及 `node scripts/reading-desktop.cjs --player-startup` 两个流程均完整通过，包括字号、RAW 句间焦点、长句、连续切歌和歌名下方署名。脚本继续直接操作启动界面，不添加固定等待绕过失败探针。

## 移动网页歌词同步

- 作词、作曲只显示在封面页歌名正下方，优先使用歌曲真实署名，缺少时从歌词中的署名补充；同作者合并，缺值隐藏，歌词页不放底部署名。
- 首次桌面同步保存目标进度，在音频元数据就绪后跳转；加载期间保留显示的进度，首次进入仍由用户点击播放。歌曲与歌词按同一音频路径匹配，不沿用桌面列表序号；首次加载期间断线不丢弃同曲的有效歌词。
- 歌词页挂载、歌词文本到达、暂停与跳转时立即定位，不等待下一次 `timeupdate`。逐字填充和活动行使用同一个音频时钟。
- 每次切歌隔离歌词、播放与历史进度请求；旧结果不得修改新歌，手动跳转优先于迟到的历史进度。
- 一起听按元数据就绪对齐，保留远端暂停状态和小于三秒的进度，去掉固定延时跳转；重连后重新接受服务器的消息序号。
- 手动浏览歌词暂缓跟随六秒；同时间戳原文与译文同时突出。暂停、隐藏页面和卸载时停止逐帧刷新并清理监听。
- 手机当前歌词字号仅在设置的歌词区域调整，最高 60px；普通字号 16–36px 收于高级选项，分别即时生效并本地保存，下一组开始时上一组才恢复普通字号，句间和末句不提前收回；歌词页通过按钮或滑动返回封面。未唱使用主题主要文字色（深色白、浅色石墨），已唱彩色，当前行放大加粗。手动浏览中调整字号不抢回当前行，最大字号支持窄屏换行。

## 播放与歌词的实现依据

| 特性 | 技术机制与状态边界 |
| --- | --- |
| 连续播放与快速切歌 | `playerService` 持有媒体实例；播放版本隔离歌词、试听、media.play 异步结果，独立封面编号拒绝迟到提色 |
| 启动期间先播放 | 并发加载歌曲/用户数据；原数据完成前不保存；早期操作按函数顺序重放，迟到自动恢复检查播放版本 |
| 上一首与随机历史 | 洗牌计划与成功播放历史分开；`playing` 事件记历史，按路径过滤删除/不推荐歌曲，回退后先沿旧历史前进 |
| RAW/KRC、增强和普通 LRC | 统一秒级模型；RAW 字偏移相对行起点，LRC offset 从毫秒换算；活动行二分查找，同时间戳原文/译文成组 |
| 当前行与已唱填充 | 焦点持续到下一组开始；填充按 `(time-start-offset)/dur` 钳制；字时长结束不触发焦点缩回 |
| 主歌词跟随 | rAF 直接读取实际媒体时间，暂停/seek 即时刷新；手工浏览六秒后跟随，长行在可读区换行 |
| 桌面歌词时钟 | 每 200ms IPC 锚点，独立窗口以 performance.now × playbackRate 外推；每次打开完整快照并确认本次 DOM 提交后显示 |
| 桌面窗口锁定 | 透明置顶 BrowserWindow，鼠标穿透 forward:true；软件内开关与锁定控制，位置和锁定偏好写 settings |
| 封面与歌词颜色 | RGBA/BGRA 归一化后按像素分桶；渲染层对比度调整；自定义优先，歌词取色与全局 themeFollowCover 分开 |
| 手机歌词与系统播放控制 | 元数据就绪后 pendingSeek，songRequest/seekRevision 防旧响应；可见且播放中 rAF，MediaSession 媒体事件更新 |
| 手机一起听 | 主进程 IPC 连接实际桌面播放器；WS welcome / state 提供完整歌曲、播放态、进度和倍速，seq 排旧操作，默认关闭、退出不暂停电脑 |
| 近期曲风统计 | 实际墙钟聆听秒数，跨午夜拆分并保留 90 天；近期 7/30 天多标签均分，手工标签优先 |

以上是源码机制说明，不是本次重新执行全部应用测试的记录。文档静态检查与应用回归各有范围，第三方账号和音源可用性须使用真实服务另行验证。
